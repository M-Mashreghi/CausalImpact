# Methodological References

This file records foundational references motivating important implementation guardrails.

- Fabijan et al. / Microsoft Experimentation Platform materials on Sample Ratio Mismatch and experiment trustworthiness.
- Chernozhukov et al., *Double/Debiased Machine Learning for Treatment and Causal Parameters* — orthogonal scores and cross-fitting for ML nuisance functions.
- Sun & Abraham, *Estimating Dynamic Treatment Effects in Event Studies with Heterogeneous Treatment Effects* — contamination of conventional TWFE event-study coefficients under heterogeneous staggered treatment timing.
- Callaway & Sant'Anna, *Difference-in-Differences with Multiple Time Periods* — group-time treatment effects for multiple periods / staggered adoption.

The implementation should cite exact method references in user-facing research reports when a method is enabled.
