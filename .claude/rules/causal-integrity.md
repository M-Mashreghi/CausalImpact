# Causal Integrity Rules

Before estimation, answer:

1. What is treatment?
2. What is outcome?
3. What is target population?
4. What is estimand?
5. What identifies it?
6. Which variables are pre-treatment?
7. Which variables are descendants of treatment?
8. Is interference plausible?
9. Is positivity / overlap plausible?
10. Which diagnostics can invalidate or weaken the claim?

Never convert an identifying assumption into a factual statement just because a model ran successfully.
