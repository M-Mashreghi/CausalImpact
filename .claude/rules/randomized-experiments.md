# Randomized Experiment Rules

Required trust checks before ship/no-ship inference:

- assignment integrity,
- sample-ratio mismatch,
- logging completeness,
- attrition / missing outcomes,
- baseline balance diagnostics,
- metric definition validity.

Prefer ITT as the default causal effect of assignment. Per-protocol comparisons are not causal by default.

Guardrails and multiplicity policies must be declared before automated decision labels are produced.
