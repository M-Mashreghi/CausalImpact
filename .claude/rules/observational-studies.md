# Observational Study Rules

Workflow:

1. define treatment/outcome/population,
2. define causal graph / adjustment set,
3. restrict to pre-treatment covariates,
4. inspect overlap,
5. estimate nuisance functions where needed,
6. estimate effect,
7. diagnose balance and weights,
8. perform sensitivity / robustness,
9. report residual assumptions.

Matching, weighting, regression adjustment, and ML do not eliminate unmeasured confounding by themselves.
